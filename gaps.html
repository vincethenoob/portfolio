GAP ANALYSIS
& ROADMAP

A comparison between where my skills are now and what the backend, cloud-aware, security-conscious roles I am targeting will require from me next.

Current vs Required

Five Priority Gaps

Each gap connects a current limitation to a practical next action instead of treating improvement as a vague goal.

01
Cloud & DevOps

Cloud Computing (AWS / Azure)

Current State

Current exposure is sandbox-level. AWS experience currently includes using S3 to host a static site.

Career Requirement

Backend and infrastructure-oriented roles require stronger cloud deployment, service configuration, and infrastructure knowledge.

Gap

The current experience proves initial exposure, but not yet independent work with production-style cloud systems.

Action Plan

Study through 2026, complete AWS Cloud Practitioner or an equivalent foundation, then work toward an associate-level certification and deploy additional personal projects in the cloud.

02
Security

Cybersecurity Fundamentals

Current State

Current experience is introductory: common attack-vector coursework, with no hands-on security project yet.

Career Requirement

Fintech, healthcare IT, and backend roles need secure system design, basic hardening practices, and an understanding of common application risks.

Gap

Theory is ahead of hands-on practice, especially for applying security controls to a real application.

Action Plan

Complete an introductory cybersecurity course or Security+ preparation, practice in lab environments, and apply basic hardening to personal deployed projects.

03
Backend

Backend & API Design

Current State

Current experience includes PHP/MySQL web work and a stated interest in full-stack development and system design.

Career Requirement

The target junior backend path requires stronger schema design, API design, validation, maintainability, and end-to-end service ownership.

Gap

Current project experience needs to progress from implementing features to deliberately designing the backend interface and data model.

Action Plan

Build a larger personal backend project focused on schema and API decisions, then document those decisions as part of the project case study. Use Django/API study as a future learning direction rather than claiming current Django proficiency.

04
Deployment

Production Deployment & Monitoring

Current State

The current cloud example is a static site on S3; the career plan explicitly identifies production deployment and monitoring as a skill still to build.

Career Requirement

A junior developer should be able to deploy a small application, inspect logs or health signals, troubleshoot issues, and understand the path from local code to a running service.

Gap

Static hosting does not yet demonstrate deployment and monitoring of a small production-style application.

Action Plan

Deploy one personal application beyond static hosting, add basic logging and monitoring, document the deployment steps, and include the live system as evidence in the Projects page.

05
Communication

Multimedia & Presentation

Current State

The current skills inventory describes basic Canva/photo editing and strong interest in explaining technical work clearly to non-technical audiences.

Career Requirement

Technical work often needs concise demos, readable presentations, and simple visual communication for stakeholders who are not developers.

Gap

The communication foundation is present, but advanced multimedia editing and presentation polish are still limited.

Action Plan

Practice basic video editing and cleaner slide design through project demos, technical walkthroughs, or student-organization work; use those outputs as portfolio evidence.

Roadmap

Improvement Sequence

The order is designed so later work produces stronger project evidence, not just more course completion.

01 · Foundation

Cloud + Security Basics

Strengthen AWS fundamentals and complete structured security study.

02 · Build

Backend/API Project

Create one larger project where schema and API decisions are deliberate and documented.

03 · Ship

Deploy + Monitor

Run the project outside the local machine, add basic operational visibility, and capture deployment evidence.

04 · Communicate

Present the Work

Turn the finished system into a clear case study, screenshots, and a concise technical demo.

Career Alignment

Every gap should end in visible evidence.

The goal is not only to learn a topic; it is to turn the new skill into something that can be demonstrated through a deployed project, repository, documentation, or presentation.
